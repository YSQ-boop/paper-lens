## Project description

Paper Lens is an Apache-2.0 Codex plugin for trustworthy, source-grounded academic-paper reading. As of 2026-10-22, the public repository has 101 GitHub stars and two releases, v0.2.0 and v0.3.0, published 36 days apart. It addresses an ecosystem need: auditable paper analysis with page, section, equation, figure, and table anchors, deterministic validation, local PDF handling, and no telemetry.

## Why Codex credits help

API credits would fund reproducible quality evaluation and core maintenance. We will run five positive and three negative multilingual quick/deep cases, use a separate judge for grounding, coverage, uncertainty, formula/table accuracy, and unsupported claims, manually review every report, and publish only aggregate results. Credits would also support issue triage, PR review, regression generation, release checks, and security hardening for untrusted PDFs and arXiv archives.

## Public impact and maintenance

I am the primary maintainer. Paper Lens is maintained publicly with Apache-2.0 licensing, contributor, security, and privacy policies, cross-platform CI, reproducible releases, and a documented no-telemetry boundary. The project does not claim unverified model-quality scores: its baseline schema and deterministic tests are public, and reviewed aggregates will exclude PDFs, private prompts, raw traces, credentials, and private paper content.
